# Taqwim

Hijri and Gregorian date converter with Egyptian holidays.

**Live: https://mostaaafaomran-ctrl.github.io/taqwim/**

Hijri to Gregorian and back, today's Hijri date, and the next Islamic and Egyptian holidays with countdowns. Offline.

## Features

- Convert both ways, with a day-offset button for moon-sighting differences
- Today in Hijri and Gregorian, in Arabic and English
- Next 10 Islamic and Egyptian holidays with days remaining
- Uses the Umm al-Qura calendar from the browser (Intl), no data files

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Privacy

Everything runs in your browser. Nothing is uploaded and there is no account.
